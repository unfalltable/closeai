# 在 VS Code 和 IntelliJ IDEA 中使用 CloseAI

CloseAI 支持浏览器、桌面端、手机，以及 **VS Code 侧栏和 IntelliJ IDEA 工具窗口**。同一账号共用模型账号、额度、项目会话和 Skills；插件直接操作当前 IDE 已授权的本机工程。

## 第一次使用

1. 在 IDE 中打开本机工程。VS Code 点击活动栏 CloseAI 图标，IDEA 打开 CloseAI 工具窗口。
2. 点击“在浏览器登录”，在 CloseAI 官网注册或登录，核对授权信息后返回插件。
3. 点击“连接并开始对话”，在 IDE 的确认框中核对完整工程路径并授权。只授权当前工程，不会自动切换到其他设备或项目。
4. 新用户如没有可用模型账号，点击“添加账号或购买”，前往官网模型账号页完成添加或购买，再返回插件刷新。
5. 在输入区选择模型账号、模型、推理强度和任务权限，查看剩余额度，开始对话。文件写入、命令和 Git 操作按所选权限执行。

注册、账号购买、套餐及完整设备管理在系统浏览器中完成。插件提供工程聊天和任务操作，不是逐字实时补全插件。未授权目录需要再次确认；IDE 和当前工程保持在线，任务才能访问其中的文件。

## 上传大文件或整个项目分析

- 在网页或插件聊天中点击附件按钮，或把文件/目录拖入输入区。**单文件最高 5 GiB**，同时受账号剩余存储空间限制。
- 直接拖入目录时，浏览器会整理为 ZIP；目录最多 **256 MiB、10,000 个条目**。更大的项目请先在电脑上压缩为 ZIP，再作为大文件上传，避免页面打包占用过多内存。
- 连接授权的在线执行设备后，可让 AI 按需解压、查找和分析项目。上传成功不表示整个项目会一次性进入模型上下文。
- 源码已在 IDE 当前工程或 Git 仓库中时，可直接使用插件连接工程，或在授权的执行设备克隆仓库，无需反复上传完整项目。
- 打包前检查内容，移除不准备分享的 `.env`、私钥和个人资料；通常也可排除 `node_modules`、构建产物和 `.git` 历史，减少传输量。上传不会自动替你排除这些文件。

附件保存在私有对象存储，下载仍需登录和所属账号权限。直传不可达时会自动使用同域分片上传；每片不超过 8 MiB，重试可从已接收的位置继续。只有大小与 SHA-256 校验完成后，附件才显示为可用。
